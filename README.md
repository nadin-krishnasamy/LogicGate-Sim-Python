# Logic Gate & Circuit Simulator 🔌

## 📌 Project Overview
As an AIML student, understanding the hardware layer is crucial. This project simulates fundamental digital logic gates (AND, OR, XOR) using Object-Oriented Programming (OOP) in Python. 

## 🛠️ Features
- **Class-Based Logic:** Modular design allowing for easy expansion to Full-Adders.
- **Half-Adder Simulation:** Combined gates to perform binary addition.
- **Mathematical Documentation:** Built using Boolean algebra principles.

## 🧮 Logic Equations
Using LaTeX for precision:
- **Sum:** $S = A \oplus B$
- **Carry:** $C = A \cdot B$

## 🚀 How to Run
1. Clone the repo: `git clone https://github.com/YOUR_USERNAME/LogicGate-Sim-Python.git`
2. Run the script: `python src/logic_simulator.py`
